# CEFR placement is decoupled from competency seeding

Assigning a level as "the highest band where seeded competencies average >= 0.5" cannot work, because the onboarding sessions must use stimuli pitched at some band before the band is known: probe at A2 and a B2 speaker scores 1.0 on A2 competencies while producing no evidence at all about B1 or B2 ones, so their average is undefined rather than high. Placement now runs off a global complexity read of the speech itself — sentence length, subordination, lexical range, error density — which needs no band-specific content because it measures the language rather than checking a syllabus. Competency seeding then happens inside the placed band.

## Consequences

The two jobs of the four-minute assessment are now independent: one sets the band, the other fills the learner model so no fixed dimension starts empty. Because only A2 content is authored, the MVP places everyone at A2 — but by a mechanism that is honest and will place higher the moment B1 content exists, rather than one that only appeared to work.
